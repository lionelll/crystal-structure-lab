# 材料基 · 晶体结构 3D 可视化实验室

基于 React、Vite、TypeScript 和 Three.js 的晶体结构 3D 交互教学网页。

## 功能

### 纯金属晶体

- FCC / BCC / HCP 晶体结构切换
- 晶胞模型、堆垛模型、空间点阵、密排面 / 密排方向、配位数、四面体间隙和八面体间隙
- 晶胞框线、晶系坐标轴、2×2×2 相邻晶胞、自动旋转和重置视角

### 离子晶体（v1.1.0）

- CsCl、NaCl、立方 ZnS、六方 ZnS、CaF₂、CaTiO₃、TiO₂（金红石）、SiO₂（β-方石英）和 MgAl₂O₄ 共 9 种结构
- 晶胞模型、空间点阵、配位数和离子位置 4 个交互模块
- 按离子种类配色，支持点击离子查看周期性配位环境或突出同类离子位置
- 右侧联动展示结构类型、点阵类型、离子位置、离子个数、配位数、结构基元和教学解析

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

本项目为纯前端静态应用，无后端依赖。
