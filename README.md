# 材料基 · 晶体结构 3D 可视化实验室

基于 React、Vite、TypeScript 和 Three.js 的晶体结构 3D 交互教学网页。

## 功能

- FCC / BCC / HCP 晶体结构切换
- 刚性球模型与球棍模型
- 晶胞框线、坐标轴、原子编号、2×2×2 阵列显示
- 密排面 / 密排方向、配位数、致密度、四面体间隙、八面体间隙、碳原子嵌入模块
- 右侧参数、公式、APF 对比图和教学解析联动
- 爆炸拆解、截面查看、自动旋转、重置视角和截图保存

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

本项目为纯前端静态应用，无后端依赖。
